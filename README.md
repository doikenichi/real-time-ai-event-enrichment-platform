# Answer sheets

This branch holds the answer sheets for the lab's practice drills and challenges. It's kept apart from `main` and your day branches on purpose, so you never see an answer by accident.

Read one when you've tried first, or after 15 minutes stuck:
```bash
lab answer drill-b        # current day
lab answer a 001          # a given day
```
Layout: `answers/day-NNN/drill-<a|b|c>.md` and `answers/day-NNN/<a|b|c>.md`. Each sheet has the answer, a line-by-line explanation, why this way (with the alternatives), common mistakes, and check-yourself questions.

Nothing here is merged into `main`.
